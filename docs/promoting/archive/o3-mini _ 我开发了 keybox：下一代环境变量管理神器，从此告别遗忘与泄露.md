## 什么是 KeyBox？

你是否还在为传统的环境变量管理方式烦恼？KeyBox 采用全新的【零信任加密】和【多值变量管理】理念，将配置管理从繁琐、低效、安全隐患累累的旧模式中彻底解放出来。

- **零信任加密**：端到端的加密技术，确保每一个敏感数据都绝对安全，哪怕你手中的环境变量也能做到隐私保护级别的加密存储。
- **多值变量管理**：支持同一变量存储多个版本，每一次更新和回滚都更加灵活便捷，让你无需再为不同环境下的配置烦恼。

## 核心亮点抢先看

### ⚡ CLI 自动集成

忘掉繁琐的手动配置，通过智能生成环境变量文件，轻松实现项目自动化搭建。类似“KeyBox login”、“KeyBox list”、“KeyBox pull”这样的命令，一键执行，让命令行生出无限魅力！

### 🌐 多端无缝对接

项目采用 monorepo 架构：
- **前端**：基于 Next.js 14 的现代化 Web 界面，实现极致的用户体验；
- **后端**：采用 Express 搭建的 API 服务，稳健可靠；
- **数据库**：通过 Supabase 轻松管理，每一次状态变更都实时同步；
- **状态管理**：Jotai 和 React Query 使得前后端状态实时响应，毫不拖沓。

### 🛡 安全与合规并重

无论是传输过程中的 TLS 加密，还是存储时使用的高强度加密算法，KeyBox 都满足企业级的安全标准。加上完善的访问控制和审计日志，让每一次操作都有迹可循。
